# 认知与记忆基础

自主认知从预算预检开始共用 45 秒截止时间。取消信号传到状态读取等待、召回、环境读取、生成和输出校验；模型生成阶段到期记为 `model_timeout`，其他阶段到期记为 `cognition_timeout`。

`buildCognitiveContext` 统一构建最多 30,000 字符的 JSON 输入。身份、当前身体、权限、预算、实时环境及正在执行的行动优先保留。历史中的 UNKNOWN 行动单独选取，不当作正在执行。其他资料按类别预留容量，依据话题和新近程度选取完整条目，剩余容量在类别间重新分配。不会截断 JSON、正文或资源标识，也不会删除数据库存档。

关系只携带近期来源样本；近期事件引用自身的原始记录，避免递归展开整个来源档案。保留的来源另有索引；被裁去的记忆同步从召回线索和阅读引用中移除。理解目标仍要求引用本轮实际提供的记忆。

自我模型投影包含稳定身份、当前有效倾向、相关成长证据和未解决的冲突。按类别和标签归并重复倾向，个人经历按内容区分；显式失效、有效期、替代关系优先。无法确定的相反记录并列标为 `conflicted`，不会自动改写身份。当前条目保留版本、来源和先前版本标识；没有显式版本的旧记录使用原档案序号。

`searchSnapshot(state, query, limit, options)` 必须提供当前状态，执行关键词、语义候选、关联扩展和重排。`searchArchive` 是名称明确的存档 SQL 查询。自主召回将近期对话和目标合并为一次检索；5 秒内无法完成时取消等待，使用当前状态的本地关键词证据，标记 `recall_degraded`。向量查询缓存使用模型、任务类型与文本 SHA-256，最多保留 512 项；文档索引继续复用数据库中的模型与内容指纹。

每日诊断写入 `data/logs/cognition-YYYY-MM-DD.jsonl`，日期采用香港时区。日志记录结果代码、阶段耗时、裁剪条目数、输入字符数和召回降级原因，不记录提示词、记忆正文或密钥。主要代码：`context_overflow`、`recall_degraded`、`budget_exhausted`、`model_timeout`、`authentication_error`、`invalid_model_output`、`cognition_timeout`、`stopped`。

构建后重启应用生效。没有数据库表结构迁移，也不需要重新导入历史。

验证：`npm run build`，随后用 Node 的 `--test` 运行 `tools` 下的测试。新增 `cognitive-context.test.mjs` 与 `cognition-foundation.test.mjs` 覆盖长期档案、来源同步、自我记录冲突、完整检索、超时取消、错误分类和向量缓存。真实存档只读回放使用替身生成器，不写入说说、不消耗自主额度。
